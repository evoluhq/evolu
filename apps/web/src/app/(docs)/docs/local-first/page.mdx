# Get started with local-first

This guide will help you get started with the Evolu local-first platform.

<Announcement>
  Upgrading from Evolu 7? Evolu 8 uses a different local storage format and does
  not migrate existing Evolu 7 databases yet. Automatic migration is planned.
  Until then, existing Evolu 7 data is preserved but is not shown in Evolu 8.
</Announcement>

<Note>
  Requirements: TypeScript 7 or newer with `exactOptionalPropertyTypes` enabled.
</Note>

<PlatformSelector />

## Installation

Evolu offers SDKs for a variety of frameworks, including React, Svelte, React Native, Expo, and others. Below, you can see how to install the SDKs for each framework.

<SinglePlatformCodeGroup>

```bash {{ title: 'React' }}
npm install @evolu/common @evolu/react @evolu/react-web @evolu/web
```

```bash {{ title: 'React Native' }}
npm install @evolu/common @evolu/react @evolu/react-native \
  expo expo-sqlite react-native-quick-crypto
```

```bash {{ title: 'Expo' }}
npm install @evolu/common @evolu/react @evolu/react-native \
  expo-sqlite react-native-quick-crypto
```

```bash {{ title: 'Svelte' }}
npm install @evolu/common @evolu/web @evolu/svelte
```

```bash {{ title: 'Vue' }}
npm install @evolu/common @evolu/web @evolu/vue
```

```bash {{ title: 'Vanilla JS' }}
npm install @evolu/common @evolu/web
```

</SinglePlatformCodeGroup>

<ConditionalPlatformAlert platform={["Expo"]} type="warning">
  **Expo Go is not supported** as it requires native dependencies
  (`react-native-quick-crypto`). **Expo web is not supported** either, because
  Metro can't bundle Evolu's web workers. For the web, use `@evolu/react-web`
  with a web bundler such as Vite or Next.js, and share the schema and queries.
</ConditionalPlatformAlert>

<ConditionalPlatformAlert platform={["React Native"]} type="info">
  Evolu uses `expo-sqlite` in React Native. Expo SDK packages work in existing
  React Native apps after [installing Expo
  modules](https://docs.expo.dev/bare/installing-expo-modules/); adopting Expo
  modules does not require removing your native projects.
</ConditionalPlatformAlert>

<ConditionalPlatformAlert platform={["Expo", "React Native"]} type="info">
  Make sure to follow the [react-native-quick-crypto setup
  instructions](https://github.com/margelo/react-native-quick-crypto#installation)
  for proper native dependency configuration. See the [react-expo
  example](https://github.com/evoluhq/evolu/tree/main/examples/react-expo) for
  required polyfills. Enable SQLCipher with
  `["expo-sqlite", { "useSQLCipher": true }]` in your app config's plugins.
  Without SQLCipher, Evolu fails at startup with an error that says how to
  enable it, instead of storing the database unencrypted.
</ConditionalPlatformAlert>

## Define schema

First, define your app database schema—tables, columns, and types.

Evolu uses [Type](/docs/api-reference/common/Type) for data modeling. Instead of plain JS types like string or number, we recommend using branded types to enforce domain rules.

```ts
import * as Evolu from "@evolu/common";

// Primary keys are branded types, preventing accidental use of IDs across
// different tables (e.g., a TodoId can't be used where a UserId is expected).
const TodoId = Evolu.id("Todo");
type TodoId = typeof TodoId.Output;

// Schema defines the database structure and mutation/query types.
// Validate untrusted input before insert/update/upsert.
const Schema = {
  todo: {
    id: TodoId,
    // Branded type ensuring titles are non-empty and ≤100 chars.
    title: Evolu.NonEmptyTrimmedString100,
    // SQLite doesn't support the boolean type; it uses 0 and 1 instead.
    isCompleted: Evolu.nullOr(Evolu.SqliteBoolean),
  },
};
// ---cut-start---

const allTodos = Evolu.createQueryBuilder(Schema)((db) =>
  db.selectFrom("todo").select(["id", "title", "isCompleted"]),
);
Evolu.assertType<
  typeof allTodos.Row,
  {
    id: TodoId;
    title: Evolu.NonEmptyTrimmedString100 | null;
    isCompleted: Evolu.SqliteBoolean | null;
  }
>();
Evolu.assertErr(Schema.todo.title.fromUnknown(""));
// ---cut-end---
```

<Note>
  Evolu automatically adds [system
  columns](/docs/api-reference/common/local-first/Schema/variables/SystemColumns-1):
  `createdAt`, `updatedAt`, `isDeleted`, and `ownerId`.
</Note>

## Create Evolu

After defining the schema, create an Evolu instance for your environment. Every instance needs an `appOwner`. Create one on the first run and persist its secret material securely, for example in Expo SecureStore or WebAuthn-backed storage, then restore the same owner on later runs:

```ts
import {
  createAppOwner,
  createOwnerSecret,
  createRandomBytes,
} from "@evolu/common";
// ---cut-start---
import { assertEqual, mnemonicToOwnerSecret } from "@evolu/common";
// ---cut-end---

// First run only. Persist the secret and restore the owner on later runs.
const appOwner = createAppOwner(
  createOwnerSecret({ randomBytes: createRandomBytes() }),
);
// ---cut-start---

assertEqual(createAppOwner(mnemonicToOwnerSecret(appOwner.mnemonic)), appOwner);
// ---cut-end---
```

The following snippets continue from the schema and `appOwner` above.

Create one shared Run for your application's Evolu instances. Omit `transports` to sync through `free.evoluhq.com`, a [testing relay](/docs/relay#hosting-evolu-relay) whose data may be deleted, provide your own relay URLs, or pass `transports: []` to disable synchronization. Set your own relays before release.

```tsx {{ title: 'React' }}
);

export const App: FC<{ children: ReactNode }> = ({ children }) => (
  <Suspense fallback={null}>
    <EvoluProvider>{children}</EvoluProvider>
  </Suspense>
);

// Call useEvolu() and useQuery() in components inside EvoluProvider.
// ---cut-start---

  db.selectFrom("todo").selectAll(),
);
const evolu = await evoluPromise;

const TodoCount: FC = () => {
  assertSame(useEvolu(), evolu);
  return <p>{useQuery(allTodos).length}</p>;
};

const { prelude } = await prerender(
  <App>
    <TodoCount />
  </App>,
);
assertEqual(await new Response(prelude).text(), "<!--$--><p>0</p><!--/$-->");
// ---cut-end---
```

## Mutate data

<SinglePlatformCodeGroup>

```tsx {{ title: 'React' }}
// ---cut-start---
import * as Evolu from "@evolu/common";
import { createEvoluBinding } from "@evolu/react";
import { createEvoluDeps } from "@evolu/react-web";
import { createRun } from "@evolu/web";
import type { FC } from "react";
import { renderToString } from "react-dom/server";

const Schema = {
  todo: {
    id: Evolu.id("Todo"),
    title: Evolu.NonEmptyTrimmedString100,
    isCompleted: Evolu.nullOr(Evolu.SqliteBoolean),
  },
};
const run = createRun(createEvoluDeps());
const evolu = await run.ok(
  Evolu.createEvolu(Schema, {
    appName: Evolu.AppName.orThrow("LocalFirstMutateReact"),
    appOwner: Evolu.testAppOwner,
  }),
);
const { EvoluContext, useEvolu } = createEvoluBinding<typeof Schema>();

const CreateTodo: FC = () => {
  // ---cut-end---
  const { insert, update } = useEvolu();

  const { id } = insert("todo", {
    title: Evolu.NonEmptyTrimmedString100.orThrow("New Todo"),
    isCompleted: Evolu.sqliteFalse,
  });

  update("todo", { id, isCompleted: Evolu.sqliteTrue });
  // ---cut-start---
  return null;
};

renderToString(
  <EvoluContext value={evolu}>
    <CreateTodo />
  </EvoluContext>,
);
const allTodos = Evolu.createQueryBuilder(Schema)((db) =>
  db.selectFrom("todo").select(["title", "isCompleted"]),
);
Evolu.assertEqual(await evolu.loadQuery(allTodos), [
  { title: "New Todo", isCompleted: Evolu.sqliteTrue },
]);
// ---cut-end---
```

## Query data

Evolu uses type-safe TypeScript SQL query builder [Kysely](https://github.com/koskimas/kysely), so autocompletion works out-of-the-box.

Let's start with a simple `Query`.

```ts
// ---cut-start---
import * as Evolu from "@evolu/common";
import { createEvoluDeps, createRun } from "@evolu/web";

const Schema = {
  todo: {
    id: Evolu.id("Todo"),
    title: Evolu.NonEmptyTrimmedString100,
    isCompleted: Evolu.nullOr(Evolu.SqliteBoolean),
  },
};
// ---cut-end---
const createQuery = Evolu.createQueryBuilder(Schema);
const allTodos = createQuery((db) => db.selectFrom("todo").selectAll());
// ---cut-start---

const run = createRun(createEvoluDeps());
const evolu = await run.ok(
  Evolu.createEvolu(Schema, {
    appName: Evolu.AppName.orThrow("LocalFirstQuery"),
    appOwner: Evolu.testAppOwner,
  }),
);
evolu.insert("todo", {
  title: Evolu.NonEmptyTrimmedString100.orThrow("New Todo"),
});
const todos = await evolu.loadQuery(allTodos);
Evolu.assertEqual(
  todos.map((todo) => todo.title),
  ["New Todo"],
);
// ---cut-end---
```

In React, `useQuery` suspends until its query loads, so render it inside `Suspense`. To load several queries at once, without a waterfall of suspensions, use `useQueries`. A query SQLite fails, for example one with a syntax error in a raw SQL fragment, throws to the nearest error boundary, while other queries and mutations keep working.

Local queries are typically fast, especially with [indexes](/docs/indexes), so preloading is rarely needed. To start loading before a component renders, call `evolu.loadQuery`; `useQuery` reuses that load unless a mutation or sync drops it first.

## Delete data

To delete a row, set `isDeleted` to `sqliteTrue` (1). Synced tables use **soft deletes**. Tables prefixed with `_` delete the row permanently and have no sync history. In the examples below, `todoId` is the ID of the row to delete.

<SinglePlatformCodeGroup>

```tsx {{ title: 'React' }}
// ---cut-start---
import * as Evolu from "@evolu/common";
import { createEvoluBinding } from "@evolu/react";
import { createEvoluDeps } from "@evolu/react-web";
import { createRun } from "@evolu/web";
import type { FC } from "react";
import { renderToString } from "react-dom/server";

const Schema = {
  todo: {
    id: Evolu.id("Todo"),
    title: Evolu.NonEmptyTrimmedString100,
    isCompleted: Evolu.nullOr(Evolu.SqliteBoolean),
  },
};
const run = createRun(createEvoluDeps());
const evolu = await run.ok(
  Evolu.createEvolu(Schema, {
    appName: Evolu.AppName.orThrow("LocalFirstDeleteReact"),
    appOwner: Evolu.testAppOwner,
  }),
);
const { EvoluContext, useEvolu } = createEvoluBinding<typeof Schema>();
const { id: todoId } = evolu.insert("todo", {
  title: Evolu.NonEmptyTrimmedString100.orThrow("New Todo"),
});

const DeleteTodo: FC = () => {
  // ---cut-end---
  const { update } = useEvolu();

  // Mark a todo as deleted
  update("todo", { id: todoId, isDeleted: Evolu.sqliteTrue });
  // ---cut-start---
  return null;
};

renderToString(
  <EvoluContext value={evolu}>
    <DeleteTodo />
  </EvoluContext>,
);
const todoById = Evolu.createQueryBuilder(Schema)((db) =>
  db.selectFrom("todo").select("isDeleted").where("id", "=", todoId),
);
Evolu.assertEqual(await evolu.loadQuery(todoById), [
  { isDeleted: Evolu.sqliteTrue },
]);
// ---cut-end---
```

When querying, filter out deleted rows:

```ts
// ---cut-start---
import * as Evolu from "@evolu/common";
import { createEvoluDeps, createRun } from "@evolu/web";

const Schema = {
  todo: {
    id: Evolu.id("Todo"),
    title: Evolu.NonEmptyTrimmedString100,
    isCompleted: Evolu.nullOr(Evolu.SqliteBoolean),
  },
};
const createQuery = Evolu.createQueryBuilder(Schema);
// ---cut-end---
const activeTodos = createQuery((db) =>
  db
    .selectFrom("todo")
    .selectAll()
    // Filter out deleted rows
    .where("isDeleted", "is not", Evolu.sqliteTrue)
    .orderBy("createdAt"),
);
// ---cut-start---

const run = createRun(createEvoluDeps());
const evolu = await run.ok(
  Evolu.createEvolu(Schema, {
    appName: Evolu.AppName.orThrow("LocalFirstActiveTodos"),
    appOwner: Evolu.testAppOwner,
  }),
);
const title = Evolu.NonEmptyTrimmedString100.orThrow("New Todo");
const { id: activeTodoId } = evolu.insert("todo", { title });
const { id: deletedTodoId } = evolu.insert("todo", { title });
evolu.update("todo", { id: deletedTodoId, isDeleted: Evolu.sqliteTrue });
const todos = await evolu.loadQuery(activeTodos);
Evolu.assertEqual(
  todos.map((todo) => todo.id),
  [activeTodoId],
);
// ---cut-end---
```

  asynchronously. See [Time Travel](/docs/time-travel) to learn how to recover
  deleted data.

## Protect data

**Privacy is essential for Evolu**, so all synced data are **encrypted end-to-end** with an encryption key derived from a cryptographically strong secret (which can be represented as a [mnemonic](https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki)) or provided by an external hardware device. The database on the device is encrypted too: on the web and in Electron always, in React Native and Expo with SQLCipher, which Evolu requires, as [Privacy](/docs/privacy#encryption-on-the-device) describes.

`evolu.appOwner` is the owner passed to `createEvolu`; it is available synchronously. For the owner created from a secret in this guide, `mnemonic` can be shown in your recovery UI.

<SinglePlatformCodeGroup>

```tsx {{ title: 'React' }}

    appName: AppName.orThrow("LocalFirstProtectReact"),

  // ---cut-end---
```

## Purge data

<Note>
  `Evolu.deleteDatabase` and `Evolu.deleteOwner` are declared but **not
  implemented yet**. Both currently throw. Implementation is planned soon.
</Note>

`deleteDatabase` is intended to remove an instance's local database. `deleteOwner` is intended to remove an owner's local rows and history and stop using that owner across tabs. Neither currently provides a working purge operation. The Evolu 7 `resetAppOwner` method is no longer available.

## Restore data

The Evolu 7 `restoreAppOwner` method is no longer available. To restore synced data, validate the user's mnemonic with `Mnemonic`, convert it with `mnemonicToOwnerSecret`, and pass the resulting secret to `createAppOwner`. Then pass that owner to `createEvolu` and connect to the relays holding its data.

Use the original `appName` to reopen the same local database on a device that already has it. Your app currently manages owner persistence, instance switching, and UI updates. Built-in account management is still being developed. Rows in `_`-prefixed tables cannot be restored from a relay because they never sync.
