# Evolu for React Native

This package provides Evolu for [React Native](https://reactnative.dev) and [Expo](https://expo.dev).

## Documentation

For detailed information and usage examples, please visit [evolu.dev](https://www.evolu.dev).

### Source, examples, and tests

The npm package includes source and tests matching the installed version in
`node_modules/@evolu/react-native/`. The links below open GitHub's `main`
branch; use the installed files when checking version-specific behavior.

- [`src/`](https://github.com/evoluhq/evolu/tree/main/packages/react-native/src/) contains the implementation and JSDoc API documentation,
  including usage examples such as those in [`Task.ts`](https://github.com/evoluhq/evolu/blob/main/packages/react-native/src/Task.ts).
- `*.test.ts` files alongside the source show tested behavior and edge cases.
  See [`Task.test.ts`](https://github.com/evoluhq/evolu/blob/main/packages/react-native/src/Task.test.ts), for example.

For application imports, use the `exports` in the installed package's
`package.json`. Relative imports in tests may access internal helpers.
