# Evolu for Svelte

This package provides Evolu for [Svelte](https://svelte.dev).

## Documentation

For detailed information and usage examples, please visit [evolu.dev](https://www.evolu.dev).

### Source, examples, and tests

The npm package includes source and tests matching the installed version in
`node_modules/@evolu/svelte/`. The links below open GitHub's `main`
branch; use the installed files when checking version-specific behavior.

- [`src/lib/index.svelte.ts`](https://github.com/evoluhq/evolu/blob/main/packages/svelte/src/lib/index.svelte.ts) contains the
  implementation and JSDoc API documentation with usage examples.
- [`src/lib/index.svelte.test.ts`](https://github.com/evoluhq/evolu/blob/main/packages/svelte/src/lib/index.svelte.test.ts) shows tested
  behavior and edge cases.

For application imports, use the `exports` in the installed package's
`package.json`. Relative imports in tests may access internal helpers.
